This is my literate configuration file for the i3 window manager
and some associated programs to help control things like;
- application launchers
- wallpapers

All settings only apply to X11 environments.
For wayland, see alternative window managers/compositors like sway, hyperland, etc.

I use these same dotfiles across multiple devices running different linux distros.
For example,
- on my desktop pc, I run i3 on debian 13
- on my m1 macbook air, I run i3 on [[https://asahilinux.org/fedora/][asahi linux fedora remix]]
Everything should work on other distros/hardware
as long as the main dependencies are installed.

I got this script from here:
https://ansonvandoren.com/posts/libinput-gestures-i3-workspaces/
#+begin_src shell :tangle .config/i3/scripts/next-or-new.sh
#!/bin/bash

# from https://ansonvandoren.com/posts/libinput-gestures-i3-workspaces/


CURRENT_NUM=$(i3-msg -t get_workspaces | jq -r '.[] | select(.focused==true).num')
ALL_NUMS=($(i3-msg -t get_workspaces | jq -r '.[].num' | sort -n))
NEXT_WORKSPACE_NUM=0

for NUM in "${ALL_NUMS[@]}"; do
    if (( $CURRENT_NUM < $NUM )); then
        NEXT_WORKSPACE_NUM=$NUM
        break
    fi
done

if [ "$NEXT_WORKSPACE_NUM" -eq 0 ]; then
    HIGHEST_NUM=$(echo "${ALL_NUMS[@]}" | tr ' ' '\n' | sort -nr | head -1)
    [ -z "$HIGHEST_NUM" ] && NEXT_WORKSPACE_NUM=1 || NEXT_WORKSPACE_NUM=$((HIGHEST_NUM + 1))
fi

i3-msg workspace number "$NEXT_WORKSPACE_NUM"
#+end_src

** picom
[[https://picom.app][picom]] is a compositor for X11.  Start it in its normal (unshaded)
mode when the i3 session starts.
#+begin_src conf :noweb-ref i3-startup
exec --no-startup-id picom --config ~/.config/picom/picom.conf
#+end_src

It can do window shadows, transparency, blur, rounded corners, etc.
Here is my config for picom;
I like to keep most of the defaults,
but I have some of the main settings with comments for documentation purposes.
#+begin_src conf :tangle .config/picom/picom.conf
# This picom build requires an explicit backend.  GLX is also required for
# rounded corners and the redshift window shader.
backend = "glx";

shadow = false # enable/disable client-side shadows

fading = true; # fade windows in/out when opening/closing
fade-in-step = 0.05 # opacity change between steps
fade-out-step = 0.03 # opacity change when fading out
fade-delta = 5 # milliseconds between fade steps
fade-exclude = [ # window conditions to exclude from fading
  # "class_g = 'Firefox-esf'"
]

inactive-opacity = 1.0 # opacity of inactive windows
active-opacity = 1.0 # opacity of active windows
frame-opacity = 0.8 # opacity of window titlebars and borders
inactive-opacity-override = false; # let opacity set by -i override window values

inactive-dim = 0.1 # dim inactive windows
focus-exclude = [ # list of window conditions to never consider focused
  "class_g = 'Cairo-clock'"
];

opacity-rule = [ # list of opacity rules for specific window patterns
  "100:class_g = 'Picture-in-Picture'", # full opacity for PIP video windows
  "100:class_g = 'Firefox'",
];

round-borders = 1; # enable/disable rounded corners
corner-radius = 8; # pixel radius of rounded window corners
rounded-corners-exclude = [ # exclude window types from rounding
  "window_type = 'dock'",
  "class_g = 'i3-frame'",
];
#+end_src

*** redshift toggle
I use picom to apply a red-light shift to my display for better night-time viewing experience.
Picom starts normally; the keybinding replaces it with the shader-enabled compositor,
and pressing it again restores normal compositing.  This works through a keybinding in
my =~/.config/i3/config=:
#+begin_src conf :noweb-ref i3-keybinds
bindsym $mod+F1 exec --no-startup-id ~/.config/i3/scripts/picom-toggle.sh 
#+end_src
which points to this script:
#+begin_src bash :tangle .config/i3/scripts/picom-toggle.sh
#!/usr/bin/env bash

config="$HOME/.config/picom/picom.conf"
shader="$HOME/.config/picom/shaders/redshift.glsl"

# A running picom with this shader means the next state is normal; otherwise
# enable the shader.  Stop the old compositor before starting its replacement.
if pgrep -a -x picom | grep -Fq -- "$shader"; then
    picom_args=()
else
    picom_args=(--backend glx --window-shader-fg "$shader")
fi

pkill -x picom 2>/dev/null || true
while pgrep -x picom >/dev/null; do
    sleep 0.1
done

picom --config "$config" -b "${picom_args[@]}"
#+end_src

And here is the shader which applies a red shift to the screen:
#+name: picom-redshift-shader
#+begin_src c :tangle .config/picom/shaders/redshift.glsl
#version 330

in vec2 texcoord;            // texture coordinate of the fragment
uniform sampler2D tex;       // texture of the window

// Forward-declare the helper that picom provides internally.
// Do NOT give it a body — picom links in its own definition.
vec4 default_post_processing(vec4 c);

// This is the ONLY function you are allowed to define.
vec4 window_shader() {
    vec2 texsize = textureSize(tex, 0);
    vec4 c = texture2D(tex, texcoord / texsize, 0);

    // Warm the screen: cut green a bit, cut blue more.
    c.g *= 0.85;
    c.b *= 0.65;

    // Hand off to picom so dim/invert/opacity/rounded-corners still work.
    return default_post_processing(c);
}
#+end_src

** X.org settings
To scale up how system text and other elements are rendered
in terms of dpi add this to =~/.Xresources=:
#+begin_src conf :tangle .Xresources

#+end_src
~96~ dpi is the default, everything, 
so ~192~ would be 200% scaling,
~144~ is 150% scaling, etc.

# Requires: playerctl

DPMS_TIMEOUT=600  # seconds

set_dpms_on() {
    xset dpms "$DPMS_TIMEOUT" "$DPMS_TIMEOUT" "$DPMS_TIMEOUT" 2>/dev/null
}

set_dpms_off() {
    xset -dpms 2>/dev/null
}

# Start from a known state

# Blank line = no player / player exited.
playerctl --player=firefox --follow status 2>/dev/null | while IFS= read -r status; do
    case "$status" in
        Playing)
            set_dpms_off
            ;;
        ""|Stopped|Paused)
            set_dpms_on
            ;;
        *)
            # Unknown status — leave DPMS as-is
            ;;
    esac
done

*** laptop battery status
This perl script uses the =upower= cli tool to query the device battery.
It cleans up some of the formatting provided by the =upower -i /org/freedesktop/UPower/devices//<battery_name>=
to fit in the bar.

#+begin_src perl :tangle .config/i3blocks/battery
#!/usr/bin/env perl

use strict;
use warnings;
use utf8;

$ENV{LC_ALL} = 'C';

my $device = $ENV{BATTERY_DEVICE}
    || '/org/freedesktop/UPower/devices/DisplayDevice';

my $prefix = $ENV{LABEL} || '';

open my $upower, '-|', 'upower', '-i', $device
    or exit 0;

my $output = do {
    local $/;
    <$upower>;
};

close $upower;

exit 0 unless defined $output;

my ($status) = $output =~ /^[ \t]*state:[ \t]*(\S[^\r\n]*)/m;
my ($raw_percent) =
    $output =~ /^[ \t]*percentage:[ \t]*([0-9]+(?:\.[0-9]+)?)%/m;

# No usable battery information.
exit 0 unless defined $status && defined $raw_percent;

$status =~ s/[ \t]+$//;

my %state_labels = (
    'charging'          => '󰂄 ',
    'discharging'       => '󰁾 ',
    'fully-charged'     => '󱊣 ',
    'pending-charge'    => '󱧥 ',
    'pending-discharge' => '󱧥 ',
    'empty'             => '󰁺 ',
);

my $state_label = $state_labels{$status} // 'BAT: ';
my $label = $prefix . $state_label;

# Round UPower's decimal percentage to the nearest whole number.
my $percent = int($raw_percent + 0.5);

my $full_text = "$label$percent%";

my $short_text = $full_text;

# Append UPower's estimated remaining time when available.
my ($remaining) =
    $output =~ /^[ \t]*time to (?:empty|full):[ \t]*(\S[^\r\n]*)/m;

if (defined $remaining) {
    $remaining =~ s/[ \t]+$//;

    if ($remaining ne 'unknown' && $remaining ne '0 seconds') {
        # UPower reports a decimal value in minutes or hours; display it as
        # compact decimal hours (for example, "49.7 minutes" becomes "0.8h").
        if ($remaining =~ /^([0-9]+(?:\.[0-9]+)?)\s+(seconds?|minutes?|hours?)$/) {
            my ($value, $unit) = ($1, $2);
            my %hours_per_unit = (
                second => 1 / 3600,
                minute => 1 / 60,
                hour   => 1,
            );
            $unit =~ s/s$//;
            $remaining = sprintf '%.1fh', $value * $hours_per_unit{$unit};
        }

        $full_text .= " ($remaining)";
    }
}

# i3blocks output:
# 1. full text
# 2. short text
# 3. optional color
print "$full_text\n";
print "$short_text\n";

if ($status eq 'charging') {
    if ($percent >= 79) {
        print "#A8FF00\n";
    }
    elsif ($percent < 79) {
        print "#76946A\n";
    }
}
elsif ($status eq 'discharging') {
    if ($percent < 10) {
        print "#FF0000\n";
    }
    elsif ($percent < 20) {
        print "#DCA561\n";
    }
    elsif ($percent < 85) {
        print "#727169\n";
    }

    exit 33 if $percent < 5;
}

exit 0;

#!/usr/bin/env bash
# Copyright (C) 2014 Julien Bonjean <julien@bonjean.info>
# Copyright (C) 2014 Alexander Keller <github@nycroth.com>

# This program is free software: you can redistribute it and/or modify

# You should have received a copy of the GNU General Public License

# original source: https://github.com/vivien/i3blocks-contrib/tree/master/volume
# check the readme: https://github.com/vivien/i3blocks-contrib/blob/master/volume/README.md
#------------------------------------------------------------------------

# The second parameter overrides the mixer selection
# For PulseAudio users, eventually use "pulse"
# For Jack/Jack2 users, use "jackplug"
# For ALSA users, you may use "default" for your primary card
# or you may use hw:# where # is the number of the card desired
if [[ -z "$MIXER" ]] ; then
    MIXER="default"
    if command -v pulseaudio >/dev/null 2>&1 && pulseaudio --check ; then
        # pulseaudio is running, but not all installations use "pulse"
        if amixer -D pulse info >/dev/null 2>&1 ; then
            MIXER="pulse"
        fi
    fi
    [ -n "$(lsmod | grep jack)" ] && MIXER="jackplug"
    MIXER="${2:-$MIXER}"
fi

# The instance option sets the control to report and configure
# This defaults to the first control of your selected mixer
# For a list of the available, use `amixer -D $Your_Mixer scontrols`
if [[ -z "$SCONTROL" ]] ; then
    SCONTROL="${BLOCK_INSTANCE:-$(amixer -D $MIXER scontrols |
                      sed -n "s/Simple mixer control '\([^']*\)',0/\1/p" |
                      head -n1
                    )}"
fi

# The first parameter sets the step to change the volume by (and units to display)
# This may be in in % or dB (eg. 5% or 3dB)
if [[ -z "$STEP" ]] ; then
    STEP="${1:-5%}"
fi

# AMIXER(1):
# "Use the mapped volume for evaluating the percentage representation like alsamixer, to be
# more natural for human ear."
NATURAL_MAPPING=${NATURAL_MAPPING:-0}
if [[ "$NATURAL_MAPPING" != "0" ]] ; then
    AMIXER_PARAMS="-M"
fi

#------------------------------------------------------------------------

capability() { # Return "Capture" if the device is a capture device
  amixer $AMIXER_PARAMS -D $MIXER get $SCONTROL |
    sed -n "s/  Capabilities:.*cvolume.*/Capture/p"
}

volume() {
  amixer $AMIXER_PARAMS -D $MIXER get $SCONTROL $(capability)
}

format() {
  
  perl_filter='if (/.*\[(\d+%)\] (\[(-?\d+.\d+dB)\] )?\[(on|off)\]/)'
  perl_filter+='{CORE::say $4 eq "off" ? "MUTE" : "'
  # If dB was selected, print that instead
  perl_filter+=$([[ $STEP = *dB ]] && echo '$3' || echo '$1')
  perl_filter+='"; exit}'
  output=$(perl -ne "$perl_filter")
  echo "$LABEL$output"
}

#------------------------------------------------------------------------

case $BLOCK_BUTTON in
  3) amixer $AMIXER_PARAMS -q -D $MIXER sset $SCONTROL $(capability) toggle ;;  # right click, mute/unmute
  4) amixer $AMIXER_PARAMS -q -D $MIXER sset $SCONTROL $(capability) ${STEP}+ unmute ;; # scroll up, increase
  5) amixer $AMIXER_PARAMS -q -D $MIXER sset $SCONTROL $(capability) ${STEP}- unmute ;; # scroll down, decrease
esac

volume | format
